# Nishi's Purple Universe 💜

A small bilingual (English/Bangla) fan-made surprise website for Nishi.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment. The site URL will appear in Settings → Pages.

This is an unofficial fan-made tribute and is not affiliated with BTS or BIGHIT MUSIC. It uses no official BTS images, logos, audio, or lyrics.

## Music room
- BTS tracks are played through official YouTube embeds; the project does not download or re-host copyrighted music.
- Visitors can add audio files (including MP3s) from their own device. These files are played locally in the current browser session and are not uploaded to the site or a server.
- Local file selections and object URLs are cleared when the page is closed or reloaded.
- If YouTube cannot load, the player attempts the site's original Web Audio ambience and still allows local MP3 playback.
